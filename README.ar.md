> [!WARNING]
> **⚠️ تحذير وإخلاء مسؤولية:**
> هذه الأداة مخصصة لإدارة وتدوير حسابات الذكاء الاصطناعي ذاتياً عند استنفاد الحصص لمزودي الخدمة (بما في ذلك **Gemini / Google Antigravity** و **OpenAI Codex**). استخدام الحسابات عبر أطراف ثالثة أو إجراء هندسة عكسية لواجهات الـ API قد يتعارض مع شروط وسياسات مزودي الخدمة، وقد يعرض حساباتك للحظر أو الإيقاف النهائي. استخدم الأداة على مسؤوليتك الشخصية التامة.

**AiPool** هي البوابة الأقوى ذاتية التدوير وعالية التوافر، ولوحة التحكم المتكاملة لإدارة مجمعات الحسابات المتعددة للذكاء الاصطناعي. تدمج حسابات متعددة من **ChatGPT / OpenAI Codex** و **Google Gemini / Antigravity (Claude & GPT)** في واجهة برمجية واحدة متوافقة بنسبة 100% مع مواصفات OpenAI، موثوقة وذاتية المعالجة.

## 🌟 لماذا تحتاج AiPool؟ (أبرز الأسباب لتحميل الأداة)

إذا كنت تعتمد بشكل مكثف على أدوات ووكلاء البرمجة بالذكاء الاصطناعي (مثل Hermes، OpenClaw، Claude Code، Cline، Cursor، Roo Code، Aider)، فإنك تواجه باستمرار قيود معدل الطلبات (`HTTP 429`) وانتهاء الحصص اليومية والأسبوعية للنماذج.

**منظومة AiPool تقضي تماماً على توقف خدمات الذكاء الاصطناعي لديك:**
- 🔄 **تدوير ذاتي فوري بدون أي انقطاع (Zero Downtime)**: عند نفاد رصيد أحد الحسابات أو مواجهة خطأ 429، يتم تحويل طلبك تلقائياً وبأجزاء من الثانية إلى الحساب التالي المتاح دون أن يفشل طلبك أو يتوقف كودك.
- 💰 **دمج الحسابات المجانية والمدفوعة معاً**: تجميع سعات وحصص عدة حسابات (سواء كانت مجانية أو مدفوعة) لتعمل كحساب عملاق واحد برصيد غير محدود.
- ⚡ **توافق تام 100% مع واجهة OpenAI الرسمية**: تعمل بشكل فوري ومباشر مع أي أداة أو مكتبة تدعم OpenAI بمجرد تغيير رابط الـ Base URL ومفتاح الـ API.
- 🔐 **إدارة أمنية متقدمة لمفاتيح الـ API**: إمكانية توليد مفاتيح خاصة ومشاركتها مع فريقك أو أصدقائك أو تطبيقاتك مع تحديد النماذج المسموحة، حظر مزودين محددين، ووضع سقف أقصى للتوكنات لكل مفتاح.
- 📱 **لوحة تحكم تفاعلية فائقة السرعة مخصصة للجوال**: متابعة حية لاستهلاك التوكنات، صحة الحسابات، وتدفق العمليات لحظة بلحظة مع إمكانية فحص تفاصيل أي طلب بنقرة واحدة من هاتفك أو حاسوبك.
- 🛡️ **فصل صارم وحماية للخصوصية**: فلترة وتشفير المحادثات والبيانات الحساسة، مع فصل تام بين المزودين (طلبات Codex لا تختلط إطلاقاً مع Gemini).

## 🚀 أبرز المميزات والقدرات

1. **إدراك ذكي وديناميكي للحصص وأنواع الخطط**:
   - التعرف التلقائي على خطة الحساب (مجاني Free مقابل مدفوع Pro/Ultra).
   - تتبع ديناميكي لنافذة الـ 5 ساعات (للمدفوع) والحصة الأسبوعية (للمجاني والمدفوع) دون ظهور قيم ملخبطة.
   - ترتيب ذكي وأولويات جاهزية للحسابات النشطة (`ACTIVE`، `READY`، `COOLING`، `OUT`).

2. **كشف وتصنيف ذكي للمستخدمين والوكلاء (Client Telemetry)**:
   - فحص متقدم يتعرف في الوقت الفعلي على أسماء البرامج والوكلاء المستخدمين (Hermes، OpenClaw، Codex CLI، Antigravity، Claude Code، Cursor، Cline، Roo Code، Aider، Postman، cURL).
   - تدفق مباشر خاص لصفحة الـ `/api` يعزل معاملات المفاتيح المصرحة بشارات مميزة خضراء زمردية.

3. **حساب تراكمي دائم للتوكنات (Lifetime Accounting)**:
   - نظام SQLite سريع ومحمي يضمن حفظ إجمالي التوكنات المستهلكة لكل حساب ومفتاح بشكل دائم دون أن تتصفر أو تُفقد عند إعادة التشغيل.

4. **ربط وتسجيل سهل وسريع للحسابات (CLI Onboarding)**:
   - معالج إضافة متقدم `ag add` متجاوب تماماً مع شاشات الجوال ويدعم فتح الرابط مباشرة بـ `Ctrl + Click` في التيرمنال على الكمبيوتر.
   - دعم كامل للحسابات المجانية القياسية والتعيين التلقائي لمشروع `aicode-consumers` المعتمد.

## 🌟 أبرز المميزات

1. **تدوير الحسابات التلقائي**: نقل فوري وسلس للطلب إلى حساب بديل متاح داخل نفس المجمع عند حدوث خطأ 429 أو نفاد الحصص دون انقطاع الاتصال.
2. **تحكم بالنماذج بنمط الاستثناء (Opt-Out)**: تمكين كافة النماذج المتاحة افتراضياً مع شارة توضح عدد النماذج المصرح بها (`Allowed: X / Y`).
3. **تدقيق وحماية أمنية مشددة**: تسجيل تفاصيل الطلبات في قاعدة بيانات SQLite (`request_events`) مع إخفاء وتشفير أي بيانات سرية أو مفاتيح قبل حفظها.
4. **واجهة متجاوبة ومخصصة للهواتف**: تصميم يعتمد على البطاقات المتتالية، أزرار نسخ بلمسة واحدة، عدادات حية، وتنقل سلس.

## 🏛️ معمارية مجمعات الحسابات (Account Pools)

تحافظ منظومة AiPool على مجمعين مستقلين تماماً:

### مجمع Codex (Codex Pool)
تستقبل خدمة `codex.service` الطلبات الخاصة بنماذج Codex، وتحمّل الحسابات المتاحة، وتجدد الجلسات عند الحاجة، وتوجه الطلب إلى السيرفرات الرسمية، وتوثق النتيجة تحت مجمع `Codex`.

### مجمع Gemini (Gemini Pool)
تستقبل خدمة `gemini.service` الطلبات الخاصة بنماذج Gemini، وتحمّل الحسابات المتاحة، وتجدد توثيق OAuth ذاتياً، وتوجه الطلب لمزود الخدمة، وتوثق النتيجة تحت مجمع `Gemini`.

### الفصل الصارم بين المجمعات (Strict Separation)
الفصل بين المجمعات هو مبدأ ثابت لا يقبل التجاوز:
- طلبات Codex تعتمد حصراً على **مجمع Codex**.
- طلبات Gemini تعتمد حصراً على **مجمع Gemini**.
- لا يتم إطلاقاً تحويل طلب Codex إلى Gemini أو العكس.
- لا يتم استبدال النموذج أو المزود بشكل صامت في حال نفاد الحسابات.
- في حال نفاد كافة الحسابات المؤهلة للمزود المطلوب، يفشل الطلب برسالة خطأ واضحة لمنع التكاليف غير المتوقعة أو السلوك غير المتوافق.

- تدفق العمليات الموحد (Unified Live Operations Stream) لعرض أحدث العمليات من المجمعين في تسلسل زمني موحد.

## 🛠️ التثبيت والإعداد

### المتطلبات الأساسية:
- نظام Linux يعمل بنظام إدارة الخدمات systemd (Ubuntu أو Debian).
- Python 3.10 أو أحدث.
- حزم `git` و `python3-venv` و `python3-pip`.
- تثبيت Node.js و npm في حال لم تكن أداة `codex` الرسمية مثبتة مسبقاً (دعم Google OAuth مدمج تلقائياً في AiPool).

```bash
sudo apt update
sudo apt install -y git python3 python3-venv python3-pip
```

### طريقة التثبيت الرسمية:
```bash
git clone https://github.com/yjlvfe/AiPoolCodexGemini.git
cd AiPoolCodexGemini
cp config.env.example config.env
# قم بتعديل config.env للإعدادات المحلية غير السرية عند الحاجة
sudo bash install.sh
```

## 💻 إدارة الحسابات عبر التيرمنال (CLI)

استخدم الأوامر المرفقة لإضافة وإدارة الحسابات في كل مجمع:

```bash
# إضافة حساب Codex جديد:
c add

# إضافة حساب Gemini / Antigravity جديد (عبر Google OAuth):
ag add
```

### 🔑 خطوات تسجيل حساب Gemini / Antigravity عبر الـ OAuth:
عند تشغيل أمر `ag add`:
1. سيعرض التيرمنال رابط مصادقة Google OAuth رسمي.
2. انسخ الرابط وافتحه في المتصفح، وسجل الدخول بحساب Google المطلوب ووافق على الصلاحيات.
3. بعد الموافقة، سيحاول المتصفح التوجيه إلى رابط يبدأ بـ `http://localhost:...` (وقد يظهر خطأ تعذر الاتصال إذا كنت متصلاً بسيرفر VPS عن بعد).
4. **انسخ كامل الرابط الظاهر في شريط عنوان المتصفح**، ثم الصقه مباشرة في التيرمنال لإتمام التوثيق وتفعيل الحساب.

```bash
# استعراض الحسابات دون إجراء اتصال خارجي:
c list
ag list

# فحص الاستهلاك الفعلي والحصص اللحظية:
c usage
ag usage

# التبديل السريع للحساب النشط:
c switch 1   # أو عبر الاختصار المباشر: c1
ag switch 1  # أو عبر الاختصار المباشر: ag1
```

## 🤖 التكامل مع Hermes Agent و OpenClaw

يقوم نظام AiPool بربط مجمعي `codex` و `gemini` تلقائياً عبر الأوامر الرسمية للأدوات:

### إعداد Hermes Agent:
```bash
bash setup-hermes.sh
```
يقوم هذا السكربت بتحديث إعدادات Hermes الموجودة في `~/.hermes/config.yaml`، واستيراد النماذج المتاحة من الجسور المحلية، وضبط آليات النقل والحد الأدنى لمحاولات الإعادة.

### إعداد OpenClaw Gateway:
```bash
bash setup-openclaw.sh
```
يقوم بتحديث ملف `~/.openclaw/openclaw.json` وإدراج المزودين في قائمة `models.providers`.

لفحص حالة التكامل دون تعديل الإعدادات:
```bash
python3 scripts/setup-hermes.py --status
python3 scripts/setup-openclaw.py --status
```

### التأكد من حالة الخدمات:
```bash

sudo systemctl --no-pager --full status codex.service gemini.service dashboard.service
```

### فحص صحة الجسور المحلية:
```bash
curl -fsS http://127.0.0.1:8124/healthz
```
