> هذه الأداة مخصصة لإدارة وتدوير حسابات الذكاء الاصطناعي ذاتياً عند استنفاد الحصص لمزودي الخدمة (بما في ذلك **Gemini / Google Antigravity** و **OpenAI Codex**). استخدام الحسابات عبر أطراف ثالثة أو إجراء هندسة عكسية لواجهات الـ API قد يتعارض مع شروط وسياسات مزودي الخدمة، وقد يعرض حساباتك للحظر أو الإيقاف النهائي. استخدم الأداة على مسؤوليتك الشخصية التامة.

**AiPool v2.2.1 (مستقر)** هي بوابة تدوير ذاتية ولوحة تحكم لإدارة مجمعات الحسابات المتعددة للذكاء الاصطناعي:

- حسابات ومجموعات نماذج **Codex / ChatGPT**
- حسابات ومجموعات نماذج **Gemini & Claude/GPT**

توفر AiPool واجهات برمجية متوافقة بالكامل مع معايير OpenAI، وتدير التبديل الذاتي بين الحسابات عند استنفاد الحصص (HTTP 429)، وتحتسب استهلاك التوكنات التراكمي بدقة، وتوفر تحكماً كاملاً بالمفاتيح والصلاحيات عبر لوحة تحكم سريعة وأدوات تيرمنال متطورة.

---

## 🚀 الجديد في الإصدار v2.2.1

- **حصص مستقلة للمجموعات الفرعية**: فصل تعقب استهلاك نماذج Gemini عن نماذج Claude / GPT مع مؤشرات سعة مستقلة وحصص أسبوعية وكل 5 ساعات.
- **صفحة API مستقلة وإدارة المفاتيح**: مسار مخصص `/api` بواجهات متوافقة مع OpenAI، مصادقة عبر Bearer token، تقييد المزودين والنماذج المسموحة، وحدود استهلاك مخصصة.
- **تتبع توكنات دائم لا يصفر**: جدول `client_usage_counters` لحفظ التوكنات مدى الحياة حتى لو تم تدوير السجلات.
- **مؤشرات حية وتحديث تفاعلي**: استطلاع كل 3 ثوانٍ لتحديث البطاقات والاستهلاك دون الحاجة لتحديث الصفحة.
- **سجل نشاط وتفاصيل المفاتيح**: سجل طلبات حي لكل مفتاح مع عداد تنازلي للتجديد التلقائي وانتهاء الصلاحية.
- **لوحة تحكم متجاوبة ومحمية**: دعم شاشات الجوال بالكامل مع بطاقات مكدسة وأزرار نسخ مباشرة.

## 🛠️ التثبيت والتشغيل

### المتطلبات:
- نظام Linux مدعوم بـ systemd (Ubuntu / Debian).
- Python 3.10 أو أحدث مع `python3-venv` و `python3-pip`.
- Git.

```bash
git clone https://github.com/yjlvfe/AiPoolCodexGemini.git
cd AiPoolCodexGemini
cp config.env.example config.env
sudo bash install.sh
```

## 💻 إدارة الحسابات عبر التيرمنال (CLI)

```bash
# إضافة حساب جديد
c add      # لحسابات Codex
ag add     # لحسابات Gemini / Antigravity

# استعراض الحسابات المسجلة
c list
ag list

# فحص الرصيد والاستهلاك الفعلي
c usage
ag usage

# التبديل السريع بين الحسابات
c switch 1   # أو اختصاراً c1
ag switch 1  # أو اختصاراً ag1
```
